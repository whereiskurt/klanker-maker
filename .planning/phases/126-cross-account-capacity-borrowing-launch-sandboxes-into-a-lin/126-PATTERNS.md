### `pkg/aws/assume.go` (NEW — utility/service, request-response)

**No positive analog exists in this codebase** — this is confirmed (RESEARCH.md + re-confirmed
this pass via `grep -rn "stscreds\|AssumeRoleProvider"`) to be the first `stscreds` use anywhere
in the repo. The closest *structural* precedent (same problem: build a second `aws.Config` for a
different account) is the **anti-pattern** below — cite it explicitly in the plan so the
implementer sees exactly what NOT to copy.

**Anti-pattern — DO NOT COPY** (`internal/app/cmd/uninit.go:244-271`):
```go
stsClient := sts.NewFromConfig(tfCfg)
assumeOut, assumeErr := stsClient.AssumeRole(ctx, &sts.AssumeRoleInput{
	RoleArn:         awssdk.String(roleARN),
	RoleSessionName: awssdk.String("km-uninit"),
})
if assumeErr == nil {
	...
	orgsClient = organizations.NewFromConfig(orgsCfg)
} else {
	// AssumeRole failed — fall back to current profile (same as doctor.go pattern).
	fmt.Printf("  [warn] AssumeRole into %s-org-admin failed: %v — using current credentials for SCP cleanup\n", cfg.GetResourcePrefix(), assumeErr)
	orgsClient = organizations.NewFromConfig(tfCfg)
}
```
This is a **one-shot, non-refreshing** credential set (no `stscreds`, no `aws.NewCredentialsCache`)
AND it **fails open** — on `AssumeRole` error it silently keeps using A's own credentials. That
fallback is correct for `km uninit`'s best-effort SCP cleanup use case; it is a **serious
correctness bug** if copied into the capacity check (Pitfall 2 — would silently check A's
64-vCPU quota while believing it checked B's 768). `pkg/aws/assume.go` must fail closed: a failed
`AssumeRole` is a hard error for any launch requiring B's quota.

**Correct shape** (from RESEARCH.md Code Examples, cross-checked against `pkg.go.dev` — treat
this as the target implementation, not a codebase excerpt, since no prior implementation exists):
```go
// pkg/aws/assume.go (new)
func AssumeRoleConfig(ctx context.Context, base aws.Config, roleARN, externalID, region string) (aws.Config, error) {
	stsClient := sts.NewFromConfig(base)
	provider := stscreds.NewAssumeRoleProvider(stsClient, roleARN, func(o *stscreds.AssumeRoleOptions) {
		o.RoleSessionName = "km-capacity-check"
		if externalID != "" {
			o.ExternalID = aws.String(externalID)
		}
	})
	cfg := base.Copy()
	cfg.Credentials = aws.NewCredentialsCache(provider) // REQUIRED — AssumeRoleProvider does not self-cache
	cfg.Region = region
	return cfg, nil
}
```
Call-site composition against the existing `LoadAWSConfig` test-seam var (`pkg/aws/client.go:28`,
confirmed to be a package-level `var` not a `func` — deliberate test-injection point, same idiom
`AssumeRoleConfig` should follow: expose it as a `var` too if `create.go`/`capacity.go` tests need
to stub it).

func (s *DynamoCapacityStore) itemKey(instanceType, az string) map[string]dynamodbtypes.AttributeValue {
