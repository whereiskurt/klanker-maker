<objective>
Add `network_placement` to `SandboxMetadata` and thread it through the DynamoDB
marshal/unmarshal chokepoint in `pkg/aws/sandbox_dynamo.go`.

Purpose: placement itself is fixed at EC2-launch time and cannot change, but the
`km init` refuse-to-disable-NAT guard (Plan 06) and the `km doctor` checks (Plan 07) both
find running private sandboxes by reading this attribute. If the field is dropped on a
`km pause` / `km resume` cycle — the documented lossy-round-trip footgun in this repo —
those guards silently miss genuinely-private sandboxes and the operator can tear NAT out
from under a live box.

Output: one struct field and one write plus one read site at the shared chokepoint, with
round-trip tests.
</objective>
