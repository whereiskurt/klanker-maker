<objective>
Add the phase's two dormant-by-default toggles: the install-level `network.nat_gateway`
key in `km-config.yaml`, and the per-profile `spec.network.privateSubnet` field.

Purpose: these are the two knobs the whole phase hangs off. They are deliberately
decoupled — NAT may exist with zero private sandboxes, and a private profile may be
authored while NAT is off (that combination is rejected at `km create`, not at
`km validate`, because the profile is not wrong, the install state is).

Output: a new `NetworkConfig` block in the config layer with the merge-list entry that
keeps it from being silently ignored, a new bool on `NetworkSpec` plus its JSON-schema
property, and a demo profile for the live UAT.
</objective>
