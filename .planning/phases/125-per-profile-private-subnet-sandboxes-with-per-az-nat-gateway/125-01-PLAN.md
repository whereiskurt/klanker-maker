<objective>
Create `infra/modules/network/v1.1.0` — a copy of v1.0.0 restructured so NAT is
**per-AZ** — and wire the install-level toggle into the live unit via
`tobool(get_env("KM_NAT_GATEWAY_ENABLED", "false"))`.

Purpose: Phase 124's AZ-failover sweep rotates sandboxes across all four AZs. A single
shared NAT would put cross-AZ data-transfer charges on every egress byte and make one AZ
a SPOF for the whole install's internet access. One NAT + EIP per AZ removes both.

Output: a new module version directory (v1.0.0 untouched), a live unit that reads the
toggle from the environment instead of a hardcoded `false`, and a Go structural
regression test over the new module.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sandbox ENI -> internet | Egress leaves the VPC. With NAT enabled it leaves via a NAT gateway EIP instead of an instance-attached public IPv4. |
| operator env -> Terraform | `KM_NAT_GATEWAY_ENABLED` crosses from the operator's shell into a Terraform bool that provisions billable infrastructure. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-125-01 | Information Disclosure | egress path via NAT | low | accept | NAT changes the *path* of egress, not whether it is filtered. The `spec.network.egress` allowlist runs at the instance/cgroup level (security groups + eBPF/proxy sidecars), upstream of NAT, and is untouched by this plan. This phase is net security-POSITIVE — it removes public IPv4 exposure for opted-in sandboxes. Re-proved live by UAT step 4 (Plan 09). |
| T-125-02 | Information Disclosure | shared per-AZ NAT EIP | low | accept | All sandboxes in one AZ share that AZ's NAT EIP as their observed source IP. Inherent to NAT, not introduced by this change. Documented as an accepted property in Plan 09's operator-doc task. |
| T-125-03 | Denial of Service | EIP regional quota | medium | mitigate | The default EIP quota is 5 per region and four NAT EIPs consume most of it. The toggle defaults off; Plan 07's `km doctor` NAT-idle WARN tells the operator when the four EIPs are being paid for with nothing using them, and Plan 09's UAT step 6 proves clean teardown returns them. |
| T-125-04 | Tampering | Terraform module source pin | low | mitigate | v1.0.0 is left byte-identical; the new behaviour lives only in a new version directory, and Task 3's `TestNetworkModuleV110IsAdditive` asserts that. No package-manager install occurs in this plan, so no package-legitimacy checkpoint applies. |

ASVS level 1. No high-severity threats — nothing here blocks.
