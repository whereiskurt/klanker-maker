<objective>
Bump ec2spot to v1.3.0 (rename `public_subnets` to `sandbox_subnets`, add
`associate_public_ip`), and restructure the sandbox terragrunt template's module version
pin from ONE shared literal into a **per-substrate lookup**.

Purpose: `infra/templates/sandbox/terragrunt.hcl:43` interpolates `substrate_module` but
hardcodes `/v1.2.0` as a single literal shared by both substrates. Two consequences: the
v1.3.0 bump is inert unless this file is restructured, and — independently of this phase —
`infra/modules/ecs/` only has a `v1.0.0`, so that same literal already points the ECS
substrate at a nonexistent `ecs/v1.2.0`. Making the pin per-substrate is the only way to
land the ec2spot bump cleanly, and giving ECS `v1.0.0` (the one version that exists) is
not optional once the lookup is per-substrate.

Output: a new immutable ec2spot version directory, a per-substrate version map in the
template, and a regression test that fails if any substrate is ever pinned at a
nonexistent module directory again.
</objective>
