<objective>
Thread private placement through the compiler: add `PrivateSubnets`, `NATGatewayIDs` and
`SandboxSubnets` to `compiler.NetworkConfig`, rename the EC2-side subnet field and template
line to `sandbox_subnets`, and emit `associate_public_ip` derived from
`spec.network.privateSubnet`.

Purpose: the ec2spot module variable was renamed in Plan 02, so the compiler must emit the
new name or `terraform init` fails on an unknown variable. The `associate_public_ip`
emission is what actually removes the public IPv4 from a private sandbox — without it the
instance gets an unroutable, billable public IPv4 in a private subnet.

Output: a compiler that emits ec2spot v1.3.0-shaped inputs, with the ECS path deliberately
left alone.
</objective>

    - .planning/phases/125-per-profile-private-subnet-sandboxes-with-per-az-nat-gateway/125-RESEARCH.md Finding 5 (why a single resolution point, and why the AZ sweep must not be forked)
  </read_first>
  <behavior>
    - Test 1: `EffectiveSandboxSubnets()` returns `SandboxSubnets` when it is non-empty.
    - Test 2: `EffectiveSandboxSubnets()` returns `PublicSubnets` when `SandboxSubnets` is empty — the safety fallback that stops a caller which forgot to resolve placement from compiling an empty subnet list.
    - Test 3: both empty returns empty (the docker substrate case, which supplies no subnets at all).
  </behavior>
  <action>
Add three fields to `compiler.NetworkConfig`:
- `PrivateSubnets []string` — private subnet IDs from the network module, index-paired with
  `AvailabilityZones` exactly as `PublicSubnets` is.
- `NATGatewayIDs []string` — NAT gateway IDs, also index-paired with `AvailabilityZones`;
  an empty entry or a short slice means that AZ has no NAT.
- `SandboxSubnets []string` — the RESOLVED list the sandbox ENI actually lands in. Set once
  by the caller before compilation, to either `PublicSubnets` or `PrivateSubnets`.

Document on `SandboxSubnets` that `PublicSubnets` deliberately remains populated with the
true public list throughout, because the ECS path always uses public subnets and because
anything that legitimately wants "the public subnets" must keep getting them.

Add a method `func (n *NetworkConfig) EffectiveSandboxSubnets() []string` returning
`SandboxSubnets` when non-empty and `PublicSubnets` otherwise. This is a deliberate safety
net: three separate call sites construct a `NetworkConfig` (two in `create.go`, one in
`budget.go`), and if any one of them fails to resolve placement, an empty subnet list would
make the ec2spot module fall back to self-provisioning subnets in a per-sandbox VPC — a
silent, expensive, hard-to-diagnose regression. Document that rationale on the method.

Put the three behaviour tests in `pkg/compiler/compiler_test.go`, named
`TestEffectiveSandboxSubnets_*`.
  </action>
  <verify>

  </verify>
