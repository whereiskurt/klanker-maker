<objective>
Carry the profile's enabled intercepts to the sandbox: a conditional systemd
drop-in holding base64-encoded JSON, plus the intercept hosts threaded into the
eBPF proxy-host list so the rules are reachable under `enforcement: ebpf` and
`both`.

Purpose: the sidecar (plan 02) reads `KM_MITM_INTERCEPTS`; nothing sets it yet.
This plan is the compiler half of that contract, and the place where the phase's
one dormancy guarantee has to hold — a profile that says nothing about `mitm:`
must render byte-identical user-data.

Output: `buildMITMInterceptsB64`, a guarded template section, the
`buildL7ProxyHosts` addition, and a compiler-to-sidecar contract test.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| profile → user-data shell | Operator-authored strings are embedded in a boot script that runs as root. |
| user-data → systemd unit environment | The encoded rule set becomes a process environment variable read by the proxy. |
| compiler → sidecar | Two independently-versioned artifacts must agree on a JSON shape. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-127-02 | Tampering | `mitm.conf` heredoc | high | mitigate | Rule content is base64 before it reaches the shell (no whitespace, no metacharacters in the alphabet) and the heredoc delimiter is single-quoted so no expansion occurs even if that ever changed. |
| T-127-08 | Tampering | disabled rules | medium | mitigate | `EnabledIntercepts` drops disabled rules at compile time so they never reach the box in any form; a test asserts the emitted array excludes them. |
| T-127-09 | Information Disclosure | DNS allowlist | medium | mitigate | Intercept hosts are threaded into `--proxy-hosts` only; a test pins `--allowed-dns` as unchanged, so declaring a rule cannot widen resolution. |
| T-127-10 | Tampering | wire-format drift | medium | mitigate | A contract test decodes real rendered user-data with the real sidecar parser, so a field rename on either side fails in CI rather than at boot. |
| T-127-SC | Tampering | npm/pip/cargo installs | high | accept | No package installs and no new dependency in this plan; the Package Legitimacy Gate has nothing to audit. |
</threat_model>
