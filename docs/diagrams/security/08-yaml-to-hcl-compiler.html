Architecture · the YAML → HCL compiler

Two YAML files in, one locals block out

The two inputs travel completely separate routes. km-config.yaml never reaches the compiler at all — it becomes process environment that site.hcl reads with get_env(). Only the SandboxProfile is compiled, and what comes out is not Terraform: it is a locals block that a byte-for-byte copy of the unit template reads back with read_terragrunt_config().
