Two processes on one box ask for the same credential

AWS has no notion of which uid on an instance is calling, so a uid-granular fence can only exist at the OS layer. These two traces run the same four rules against the same instance role. The interesting cell is not the first divergence — it is rule three, where a Deny inside a session policy stops a request the IAM role would otherwise have allowed.
