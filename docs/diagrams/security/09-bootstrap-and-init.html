Flowchart · bootstrap then init

What each command applies, and the two things that aren't Terraform

km bootstrap and km init are not two halves of one apply — they run different units, in different accounts, with different credentials, and two of bootstrap's resources are created by direct SDK calls with no state file at all. That is a deliberate chicken-and-egg answer, not an oversight: the KMS key and the artifacts bucket have to exist before anything can be stored in them.
