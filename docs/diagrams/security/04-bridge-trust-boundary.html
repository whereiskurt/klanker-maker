Architecture · secure paved road

A public URL that GitHub and Slack can reach, and nothing else can use

The Function URL is deliberately unauthenticated at the AWS layer — the auth is the webhook HMAC the sender already computes, verified before a single byte of the payload is parsed. The interesting property is what is missing: the Lambda has no vpc_config, so there is no network path from the bridge into the sandbox subnet. Work reaches a box only because the box asked for it.
