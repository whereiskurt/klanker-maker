Architecture · secure paved road

A public URL that GitHub, Slack and HackerOne can reach, and nothing else can use

The Function URL is deliberately unauthenticated at the AWS layer — the auth is the webhook HMAC the sender already computes, verified before a single byte of the payload is parsed. The interesting property is what is missing: the Lambda has no vpc_config, so there is no network path from the bridge into the sandbox subnet. Work reaches a box only because the box asked for it. Two HackerOne edges are drawn because they cross the boundary the other way. The bridge posts one internal "On it" comment back to the report with the API token it reads from SSM, and events.<event>.reply: none removes that write (and the frozen/quota notices) so an auto-triaged report carries no trace until a human blesses it. And with h1.debug_capture: true every raw delivery lands in h1-captures/ before the HMAC check — on purpose, so a mis-pasted secret still yields evidence.
