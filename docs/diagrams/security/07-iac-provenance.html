Swimlane · file provenance

Two files are hand-written. Everything else is produced.

The reason you cannot find a backend.tf, a provider.tf, or a region.hcl in this repository is not that someone configured them by hand somewhere else — it is that Terragrunt's generate blocks write them into .terragrunt-cache/ at runtime, and that directory is gitignored. Follow a lane and you can name the process that authored every file the apply touches.
