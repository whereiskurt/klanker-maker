Architecture · S3 + presigned URLs

Three buckets, one the sandbox can reach — and what a presign really carries

A presigned URL is not a grant. It is the box role's own credentials, SigV4-signed over one request and handed to someone without them. Whoever holds it can do exactly what the box could, on that one key, until it expires — so the interesting question is not how the klanker signs (it already has the credentials) but what those credentials are allowed to do.
